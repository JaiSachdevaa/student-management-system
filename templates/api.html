REST API

Everything you can do in the website is also available as JSON endpoints.

Endpoints

MethodPathWhat it does
GET/healthHealth check used by Docker and the pipeline
GET/api/studentsList all students
POST/api/studentsCreate a student
GET/api/students/<id>Get one student
PUT/api/students/<id>Update a student
DELETE/api/students/<id>Delete a student
GET/export.csvDownload students as CSV, supports the same filters as the dashboard

Example request body

{
  "name": "Asha Verma",
  "email": "asha@example.com",
  "course": "CSE",
  "year": 2
}

Try it from a terminal

curl.exe -X POST http://localhost:8000/api/students -H "Content-Type: application/json" -d "{\"name\":\"Asha Verma\",\"email\":\"asha@example.com\",\"course\":\"CSE\",\"year\":2}"

Status codes: 201 created, 400 invalid data, 404 not found, 409 email already exists.
